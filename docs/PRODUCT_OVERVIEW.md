# OmniDoxa Product Overview

OmniDoxa helps users understand how different political perspectives are reacting to the same story. It avoids the article-first pattern and instead creates persistent Topics from Anchor Articles, analyzes discourse across Left, Center, and Right Viewpoints, and uses real Social Posts as evidence.

## Audience

- Public visitors who want a neutral summary and a preview of the debate.
- Members who want personalized briefings and account features.
- Subscribers who want full Premium Analysis and deeper briefing capabilities.
- Admins who manage Topics, review AI output, and publish analysis.

## Product Promise

Users should see more than their own bubble. Every published Topic should show what happened, how the debate is shaped, and where real public discourse supports each Viewpoint.

## Access Model

| Role | Access |
| --- | --- |
| Anonymous visitor | Free Topic layer, locked Premium Analysis, public games |
| Member | Free Topic layer, Basic Briefing, account features |
| Subscriber | Premium Analysis, Premium Briefing, expanded features |
| Admin | Editorial management, independent from subscription |
